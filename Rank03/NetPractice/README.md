# NetPractice

A networking project made of 10 practical exercises, solved in a browser-based simulator. The goal is to configure IP addresses, subnet masks and routing tables so that all devices in each network can communicate.

**What the project covers**
- IPv4 addressing and subnet masks (CIDR notation)
- Public and private ranges
- Switches and routers
- Default gateways and routing tables

The exercises run in 42's own web tool, so there is no source code to build.
